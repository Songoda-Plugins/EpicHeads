# EpicHeads

> **[Official EpicHeads website][Plugin page]**
>
> For the latest downloads, supported Minecraft versions, documentation,
> installation instructions, compatibility information, updates, and support,
> visit the Songoda Reborn page above.

EpicHeads is a Minecraft decorative-heads server plugin developed and maintained by
**Songoda Reborn**.

It gives players a searchable catalog of decorative player heads that can be used in
builds and server environments.
